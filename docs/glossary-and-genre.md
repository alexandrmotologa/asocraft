# Category and Genre Glossaries

ASOCraft includes genre-aware terminology tables to prevent literal machine translations from replacing common mobile search queries with awkward equivalents.

## Supported genres

- `casual-game`: Puzzle games, match-3, bubble shooters, arcade games.
- `rpg`: Role playing games, dungeon crawlers, character progression.
- `action-game`: Shooters, runners, survival games.
- `productivity`: Task managers, note taking, habit trackers.
- `utility`: File cleaners, VPNs, scanners, system tools.
- `fitness`: Workout trackers, diet logs, step counters.
- `finance`: Budget trackers, expense managers, crypto portfolios.
